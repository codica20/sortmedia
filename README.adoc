# sort_media

This linux app should sort media to folders in Year/Month structure.

## Usage

For development run
```bash
  flutter run
```  

To build
```bash
  flutter build linux
```  

## Development

### Architecture

#### Features

Features contain subfolders

* ui
* uistate - state that contains code related to widgets
* state - pure state
* data - logic to calculate, fetch or combine data needed for state
